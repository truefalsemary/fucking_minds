# Как задеплоить Flutter Web версию проекта на VPS

Ниже описана инструкция для деплоя Flutter Web проекта на VPS через Gitlab Runner. Метод рассчитан на авторизацию по ssh ключам и отключенной парольной авторизации.

## Инструкция

1. Подключиться к linux vps серверу по ssh с sudo правами:
    - `ssh -i secret_key/path ADMIN_USERNAME@PROD_HOST`

2. Создать пользователя для deploy приложения на VPS:
    - `sudo adduser --disabled-password deploy-user`

3. Создать связку ssh ключей для доступа к vps под пользователем deploy-user:
    - `ssh-keygen -t rsa -b 4096 -C "lms-front"`

4. Добавить публичный ssh ключ в .ssh/authorized_keys для пользователя deploy-user:
    - `sudo mkdir -p /home/deploy-user/.ssh`
    - `sudo vim /home/deploy-user/.ssh/authorized_keys` и вставить публичный ssh ключ

5. Установить nginx сервер, который даст доступ к приложению:
    - `sudo apt update && sudo apt install nginx`

6. Запустить nginx сервер на VPS:
    - `sudo systemctl start nginx`
    - `sudo systemctl enable nginx`

7. Конфигурация nginx сервера на VPS:
    - `sudo vim /etc/nginx/sites-available/lms-front`
    -  Вставить в файл следующий конфиг:

        ```nginx
        server {
        listen 80;

        root /var/www/lms-front/web;

        index index.html;
        location / {
            try_files $uri $uri/ =404;
        }
        ```

    - Добавляем наш сайт в `sites-enabled`, чтобы он начал раздаваться nginx сервером (с помощью symlinks):
        - `sudo ln -s /etc/nginx/sites-available/lms-front /etc/nginx/sites-enabled/`

    - ОБЯЗАТЕЛЬНО удалить default файл т.к. он перезаписывает приложение:
        - `sudo rm /etc/nginx/sites-enabled/default`

8. Создание каталога под /var/www/lms-front для приложения и передача прав пользователю deploy-user на получившийся каталог:
    - `sudo mkdir -p /var/www/lms-front/web`
    - `sudo chown deploy-user:deploy-user /var/www/lms-front/web`

9. Билд flutter приложения на CI сервере/локально:
    - `cd flutter_project_root`
    - `flutter build web --release`
    - Последняя команда скомпилирует web приложения для релизной версии в папку `build/web`

10. Загрузка артифактов на prod-VPS:
    - `scp -r -i YOUR_PRIVATE_SSH_KEY ./lms_front/build/web/* $YOUR_USERNAME@$PROD_HOST:/var/www/lms-front/web`
