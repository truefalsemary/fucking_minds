# Как задеплоить Flutter Web версию проекта на VPS (Docker)

Ниже описана инструкция для деплоя Flutter Web проекта на VPS через Gitlab Runner. 
Метод рассчитан на авторизацию по ssh ключам и отключенной парольной авторизации.

При этом подразумевается, что сама VM, на которой запускается CI собирает
сервисы в готовые docker контейнеры и автоматически деплоить их на VPS.
(Либо вручную, либо посредством Docker Registry).

## Инструкция

1. Подключиться к linux vps серверу по ssh с sudo правами:
    - `ssh -i secret_key/path ADMIN_USERNAME@PROD_HOST`

2. Установить docker и docker-compose:
    - `sudo apt update && sudo apt-get install -y docker-ce docker-ce-cli containerd.io`

3. (Если используется yandex docker registry) Создать сервисный аккаунт с правами:
    - `container-registry.images.scanner`
    - `container-registry.images.pusher`
    - `container-registry.images.puller`

4. (Если используется yandex docker registry) Создать новый "авторизованный" ключ для доступа к docker registry: 
    - Алгоритм шифрования RSA_2048 или RSA_4096
    - Описание любое
    - Скачать файл с ключами (`authorized_keys.json`)

5. Загрузить файл с ключом на prod сервер и CI сервер:
    - `scp -i PRIVATE_KEY ./authorized_key.json ADMIN_USERNAME@PROD_HOST:/home/ADMIN_USERNAME`
    - `scp -i PRIVATE_KEY ./authorized_key.json ADMIN_USERNAME@CI_HOST:/home/ADMIN_USERNAME`
    - Возможно есть более предпочтительный способ авторизации, 
      но на данный момент этот ощущается самым очевидным и относительно безопасным.

6. Установить yandex cloud CLI (для авторизации в docker registry):
    - `curl -sSL https://storage.yandexcloud.net/yandexcloud-yc/install.sh | bash`

7. Авторизоваться по ключам на prod и CI серверах:
    - `yc config set service-account-key ./authorized_key.json` на prod VPS 
    - `yc config set service-account-key ./authorized_key.json` на CI VPS

8. Создать docker registry конфигурацию (для авторизации в docker registry) на базе уже введенного ключа:
    - `yc container registry configure-docker` на prod VPS
    - `yc container registry configure-docker` на CI VPS
    - После авторизации можно использовать push/pull команды docker registry

9. После авторизации файлы ключей можно (и нужно) удалить:
    - `rm authorized_key.json` на prod VPS
    - `rm authorized_key.json` на CI VPS

10. Теперь можно деплоить проект с CI VPS:
    - ВАЖНО: докер нельзя запускать с sudo, только от текущего пользователя.
      Иначе сломается процесс авторизации.
    - `docker build -t frontend .`
    - `docker tag frontend cr.yandex/<идентификатор_реестра>/frontend`
    - `docker push cr.yandex/<идентификатор_реестра>/frontend`

11. И запускать проект на prod VPS:
    - `docker pull cr.yandex/<идентификатор_реестра>/frontend`
    - `docker compose up -d`

    - При этом вид самого compose файла `docker-compose.yaml`:

        ```yaml
        version: '3'
        services:
          frontend:
            image: cr.yandex/<идентификатор_реестра>/frontend
            ...
        ```
    - Дальше это всё можно просто автоматизировать через docker compose
