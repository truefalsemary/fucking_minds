## Описание проекта

LMS - Learning Management System для создания, редактирования и ведения продолжительных закрытых курсов с большим количеством участников.

### Роли в системе:

  1. Админ - создаёт курсы и управляет ими, назначает учителей
  2. Учитель - проверяет работы учеников и поддерживает обратную связь по курсу
  3. Ученик - проходит курс и получает баллы за задания
