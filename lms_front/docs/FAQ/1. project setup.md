
# Как запустить проект

1. Получить все зависимости:
    - `flutter pub get`
2. Построить все модели:
    - `dart run build_runner build --delete-conflicting-outputs`
3. Сгенерировать l10n файлы для переводов и строк:
    - `flutter gen-l10n`
4. (Опционально) запустить фикс форматирования:
    - `dart fix --apply`
    - `flutter analyze`



# Как сделать всё одной командой

В целях автоматизации в проекте используется простой Makefile, в котором описаны все те же команды, но запускать их можно быстрее либо вовсе одной командой.

Для запуска любой команды:

```bash
make имя_таргета_например_all
```

Так `make all` выполнит всё необходимое для старта проекта.



### Как выглядит Makefile:

```Makefile
# Get all the dependencies
deps:
	flutter pub get

# For fast fixes of formatting/linter
fix:
	dart fix --apply

# For build model automation 
build_models:
	dart run build_runner build --delete-conflicting-outputs

# For fast generating l10n
l10n:
	flutter gen-l10n

# Start fixing and building everything
all:
	make deps
	make fix
	make build_models
	make l10n
```

# Но у меня нет make!

Под linux/macOS make - предустановлен в системе, для windows его можно установить командой:

```powershell
winget install -e --id GnuWin32.Make
```

### Либо скачать [напрямую](https://gnuwin32.sourceforge.net/packages/make.htm)
